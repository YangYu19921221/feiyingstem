# 加盟销售端 PPT · 生图技能配合建议

本版在现有加盟版销售演示中补入了「销售端 50% 分成」口径，并把卖点收束为：

- 招生：AI 测评漏斗、渠道归因、家长转介绍
- 留存：实时 PK、晋级赛、宠物养成、金币兑换
- 交付：AI 组卷、口语评测、老师培训、白标与多租户
- 激励：销售端按加盟实收净额享 50% 分成（最终以合作协议与结算口径为准）

推荐的技能组合：

1. `baoyu-slide-deck`：先做销售叙事、页面顺序与统一版式。
2. `baoyu-image-gen`：为封面、加盟场景、宠物留存、AI 教学、数据安全生成统一品牌视觉。
3. `impeccable`：交付前做销售端视觉审查，检查数字是否醒目、利益点是否一眼可读。
4. `gsap-core` / `gsap-timeline`：如果要做网页式招商演示，可把「招生 → 留存 → 续费 → 分成」做成连贯动效。

销售话术锚点：

> 别人给你一套课件，我们给你一套能自己跑起来的数字化教学系统；你负责找到客户，我们负责把交付跑通，成交后销售端按约定拿 50% 分成。
