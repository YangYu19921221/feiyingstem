> 状态: **第 1 期的样课已经写了,11-15 部署到线上但只有老师 / 管理员点得开**(「一般现在时」10 节小课 + 小课播放器 + 配音;学生端没有入口;

## 0. 用户提的要求(原话)

1. 「中小学生如何利用 AI 自学语法,他不懂的情况下怎么通过智能体让他搞懂」
2. 「你考虑了学生在所有学英语所有的情况没 做题听课 啥也不懂 对英语没兴趣」
3. 「小学初高中 怎么学你也要考虑 肯定是根据人教版为主 AI 除了文字输出还能应该怎么来弄 最好是一个规划 孩子对文字自学能力大部分薄弱」

## 1. 四条总原则

1. **语法去找孩子,不等孩子来问。** 小鹰老师 10 月刚上线那两天,真学生只主动问过 1 次。
   孩子在系统里做的每件事(背单词、句子填空、作业批改、对战)都留下证据,系统先知道他哪里不会,再把 3 分钟递过去。
2. **少字。** AI 的输出是 说 / 摆 / 动 / 让他动手 / 让他开口,屏幕上的字只剩一行字幕。
   画面配人声讲解,比画面配文字学得好;同样的话再在屏幕上堆一遍反而更差(多媒体学习研究里很稳的结论)。
3. **人教版是骨架。** 学校讲到哪个单元就跟到哪;不会的顺着地图往下补到断点。
4. **八成固定、两成现场。** 每个点的讲法、配音、图、题库提前生成一次、老师审一遍、全平台共用(同记忆妙招「一个词只生成一次」)。
   现场调模型只在: 孩子追问为什么 / 错得出乎意料 / 让他自己讲一遍要判对错 / 拍了课本那一页。

## 2. AI 不靠文字的办法

| 办法 | 孩子那边是什么样 | 系统里已有 | 要新做 |
|---|---|---|---|
| 说 | 小鹰老师开口讲,一次一句,画面跟着动 | 英文发音(Edge TTS 英式女声)、「听全部英文」 | 小鹰老师的中文声音(固定一个);讲解提前配好音存成文件 |
| 摆 | 句子摆成四色积木(谁 / 干什么 / 什么 / 在哪、什么时候);配情景图 | 8.9 万词条配图、出图通道 | 积木组件;每个点 3–6 张情景图 |
| 动 | 五种动作: 加尾巴(-s -ed -ing -er)、换一块(I→me、do→does)、插一块(do / not / be)、换位置(疑问句、被动)、合并和拆开(从句、长难句);另加一条时间轴讲时态 | Framer Motion | 动画模板。**程序画,不用 AI 生成视频** |
| 动手 | 听句子选图、拖积木拼句、换一块看别的块怎么变、点出错的那个词、把句子分进两个筐 | 分类学习的拖拽、练习卡服务器判分 | 这五种题型 |
| 开口 | 跟读、说一句来提问、给「小鹰同学」挑错 | 例句跟读、语音输入(说一句) | 接进小课;识别不准,**只加分不卡人** |
| 玩 | 宠物对战「句子招」: 把词块排成一句才放得出来 | 对战、拼单词放大招 | 句子招(入口照旧受场数管) |
| 纸 | 一页纸小结可打印;纸上做的题拍进来 | PDF 导出、作业批改、拍题 | 小结模板 |
| 给老师 | 全班卡在哪个点、谁要当面讲 | 本班情况页、老师出卷 | 语法点报告 |

**先不做**: AI 生成视频(画不准字、每次不一样、贵);实时语音对话(现在语音转写 6–9 秒 + 模型 7–11 秒,一来一回近 20 秒);数字人老师。

## 3. 一节「小课」长什么样

对孩子不叫语法: 小学叫「句子积木」,初高中叫「语法小课」。五步,一步一屏:

1. **听和看**: 一个情景,两三句只差一处的句子,带图带声音。
2. **找不同**: 让他点出哪里不一样。他自己发现,不是被告知。
3. **拼**: 拖积木。规则做成形状——「He」的缺口只接得上带 s 尾巴的「likes」,拼错了接不上。小鹰老师这时说一句话把规则定下来(小学配口诀)。
4. **练**: 五级,认出来 → 二选一 → 改错 → 填 → 自己拼/写。每个错的选项对应一种错法,错了针对这一种讲。
5. **教小鹰同学**: 小鹰同学故意拼错一句,让他改。小学只要把错的那块换掉;初中再选「为什么」;高中自己说或写原因,现场判。做完地图上点亮。

硬规矩:
- 每 20–30 秒孩子要动一次手,不让他干看。
- 一屏的中文不超过: 小学 15 字 / 初中 30 字 / 高中 60 字。中文讲解自动念出来。
- 只有一个大按钮往下走。小学只点和拖;初中起才有短输入。
- 例句只用人教版到这个单元为止学过的词,由程序核对(孩子的脑子只对付语法这一件事)。
- 没耳机时字幕兜底。电教室建议配耳机。
- 它是「课」不是「聊天」: 聊天要打字、读字,正是这些孩子最弱的。小课里留一个「没懂,问小鹰老师」按钮。
- 当场做对不算会。3 天后混在别的点里还做对才点亮;之后 7 天再考一次。判错满 3 次交给老师当面讲(已有)。

## 4. 三个学段各怎么学

| | 小学(三到六年级) | 初中 | 高中 |
|---|---|---|---|
| 学的是什么 | 句型,不叫语法 | 规则 + 易混对比 + 做题方法 | 句子结构 + 长难句 + 用出来 |
| 点数(估) | 约 30 | 约 45 | 约 40 |
| 术语 | 不出现;五六年级才给最简单的名字 | 会做了再给名字(主语、谓语…) | 正常用 |
| 主要办法 | 听句选图、积木、换一块看变化、口诀 | 时间轴讲时态、信号词分筐、题型的看题步骤、错题按点归类 | 长句拆成「果树」(主干是树干,修饰成分是枝叶)、两句合一句、语法填空看空三步、写作句式升级 |
| 孩子的输入 | 只点和拖 | 短填空 | 写句子 |
| 一次多久 | 3 分钟 | 5–8 分钟 | 8–10 分钟 |
| 谁来启动 | 老师布置,电教室做;小学生不会自己学 | 课后、作业批改、考前 | 自己在地图上选,错题带着走 |
| 断点常在 | 不会读词(同时走音标、拼读) | 小学层(be 和 do 混用、三单) | 初中层(句子成分、从句、时态) |
| 大致内容 | be 动词、名词单复数、代词、方位介词、There be、can、一般现在时(含三单)、现在进行时、be going to、一般过去时、比较级 | 各时态(到现在完成、过去完成)、被动、情态动词、不定式和动名词、宾语 / 定语 / 状语从句、比较等级、基本句型 | 八种基本句型、定语从句、名词性从句、非谓语(doing / done / to do)、被动各时态、虚拟、倒装强调省略、长难句 |

各一节样课:

- **小学 · There is / There are**: 听一句,三张图里点对的 → 把图里的猫从一只拖成两只,is 自己翻成 are、cat 长出 s → 看图拼句 → 把小鹰同学拼错的那一块换掉。
- **初中 · 现在完成时和一般过去时**: 时间轴上一个是「昨天的一个点」,一个是「从过去连到现在的线」→ 把 yesterday、already、since、last week 分进两个筐 → 练「先找时间词,再定时态,再看主语」→ 3 天后两个时态混着考。
- **高中 · 定语从句**: 「I know the girl. The girl won the prize.」第二句的 the girl 变成 who 挂到前面,合成一句 → 长句主干亮起来,从句是一根能折叠的枝 → 在课文句子里点出先行词和从句 → 练语法填空里没提示词的空(先行词是人是物、从句缺什么)。

衔接: 小升初、初升高各做一次 5 分钟摸底(听句选图、点选为主,不靠读长句),把孩子放到地图上。

## 5. 人教版怎么对上

- 两样东西分开做:
  - **语法地图**: 有哪些点、谁在谁前面、每个点常见的错法。不随教材变。
  - **对照表**: 哪本书哪个单元讲哪几个点。随教材版本变,按书 id + 单元 id 挂。
- 库里现状: 人教版的书都按单元在库里(10 月线上: 小学 9 本、初中 10 本、高中 7 本)。
  本机副本 11-15 看到: 三四年级、七八九年级是 2024 年起的新版(七上是 You and Me / We're Family! 那一版),五六年级标着「旧人教版」。
- **新版教材每个单元讲什么语法,不凭记忆定。** 先出初稿,老师对着课本每单元的语法页核对(或者拍照)。
- 对照表的用处: 课前 3 分钟、课后 5 分钟(班级「学校讲到哪」已经有,autopilot_class_sync.school_unit_id);老师一键布置「本单元的语法」;地图上给孩子标「课本第几单元」。
- 别的教材版本以后加一张对照表就行(word_books.series 已有)。飞鹰语法三册的讲法可以叠在同一张地图上。

## 6. 四种孩子从哪进来

| 情况 | 怎么进来 |
|---|---|
| 做题 | 卡在一道题: 拍这一道(已有),题挂到地图的点上,做完问要不要 3 分钟搞懂。做完一页: 作业批改(已有)按点归类,「错的 8 道其实是 2 个点」。知道规则不会做题: 教各题型的看题步骤。错题 3 天后换题重考。考试卷: 拍卷子,丢分按点排,考前每天补一个点 |
| 听课 | 课前 3 分钟预习明天那个点;课后 5 分钟「听懂几成」,没懂换讲法;说不清老师讲了什么就拍黑板 / 课本 / 笔记或说一句;线下语法课老师点「今天讲了哪个点」全班自动收到巩固 |
| 啥也不懂 | 积木模式,不出术语;每块有图、有中文、点一下就读;只用二三十个最常见的词;不会读的同时走音标、拼读 |
| 没兴趣 | 头三题一定做对;放进宠物对战;例句主角是他的宠物;一次 3 分钟;只和自己比;老师布置、电教室里开头。AI 变不出兴趣,只能拿掉听不懂、总是错、被比较这三样,再给小赢 |

另外顺手管的: 句子填空里把 helps 写成 help(现在已经记了,没人用)→ 连错三个递一句;读课文看不懂句子 → 点一下拆成积木;自己写句子 → 先划出错处让他自己改。

## 7. 现场的小鹰老师在这里干什么

- 回答改成「摆 + 说」: 给模型加摆积木、画时间轴、并排对比这几样工具,回答最多两句话并自动念出来,不写长段。
- 孩子提问优先「说一句」(已有),其次打字。
- 固定小课**不扣**「问小鹰老师」次数(建议);追问才按现在的规矩算。

## 8. 老师看到什么

- 每个点: 谁做完了、谁 3 天后没过、全班最多人卡的点(线下课就讲这个)。
- 一键布置: 本单元的语法 / 某个点 / 让小鹰老师每天自动带一个点。
- 内容审核页: 每个点的讲法、例句、题目逐条「通过 / 要改」。孩子也能点「这题有问题」。

## 9. 分期

| 期 | 做什么 | 过关看什么 |
|---|---|---|
| 1 | **一节样课 + 一条线。** 先做一节能点的样课给用户在手机上试,定样子。再做「一般现在时」这条线(be → do → 三单 → 否定、疑问,约 10 个点,四年级到初一)。同时出: 全部知识点名单和前置关系、人教版对照表初稿、小课播放器、积木、中文配音、三种动画、老师审核页、老师布置、点亮、老师报告 | 直营一个班试两周: 布置的小课做完率、3 天后回头考正确率、和学之前的摸底比 |
| 2 | **小学全线 + 自己找上门。** 小学约 30 个句型点(听句选图、换一块、口诀);跟学校进度的课前课后;句子填空、作业批改里的错自动记到地图;宠物对战句子招 | 没人布置时孩子进不进来;作业批改里这些点的错有没有变少 |
| 3 | **初中全线 + 做题。** 约 45 个点;时间轴、易混对比、各题型看题步骤、错题换题重考、拍卷子出考前计划;小鹰老师回答改成「摆 + 说」 | 同上,加上考前计划有没有人用完 |
| 4 | **高中。** 约 40 个点;拆长难句、从句和非谓语、语法填空、写作句式、一页纸小结 | 同上 |
| 5 | **看数据再定。** 老师真人微课挂到点上(视频那一套现成)、开口练、家长端、别的教材版本 | — |

顺序的理由: 直营在读的孩子多是小学三到六年级和初一,所以先小学和初一的地基;高中放最后。

## 10. 钱和风险

- 一次性做内容(模型生成 + 出图)估计两三千元以内;配音不花钱。之后孩子学固定小课不花模型钱。
- 讲错: 生成后机器再核一遍(每题只有一个对的答案、例句没有超纲词),老师审,孩子可举报。
- 孩子不做: 这是最大的风险,所以第 1 期只做一条线先看做完率。
- 新旧版教材对不上: 对照表按版本做,老师核对。
- 电教室没耳机: 字幕兜底,效果打折。
- 开口识别不准(真人准确率至今没验过): 不拿它卡人。

## 11. 要用户定的

1. 样课做出来后点一遍,定样子。
2. 哪位老师审内容(第 1 期约半天)。
3. 试点用直营哪个班(查缺补漏那个班如果还在试,建议换一个,两个试验混在一起看不清)。
4. 电教室有没有耳机。
5. 固定小课扣不扣次数(建议不扣)。

## 12. 开发时可以直接用的(给以后的自己)

- 布置: content_homework 加一种 kind,完成由服务器按作答现判(照 services/content_homework.py)。
- 回头考的阶梯: tutor_notes 的 1 → 3 → 7 天(到期那天或以后答对才升级)。笔记要挂知识点 id,不再靠自由文本的 topic。
- 判分: 照 tutor_quiz,答案只在服务器,第一次交的才算。
- 配图: word_art 那条出图通道;图里不让模型写字,字自己印。
- 配音: 存成静态文件;失败保持安静,不用浏览器语音兜底;英文例句仍是现在的英式女声。
- 拖拽和防误触: 分类学习那套(350ms)。
- 证据: learning_records 里 sentencefill 的 user_answer;homework_checks 的错题知识点。
- 年级: tutor_level。学校进度: autopilot_class_sync。
- 新表的模型要在 models/__init__ 里导入;上线要加公告和显眼入口。
