# 摄像头看孩子在不在座位前 —— 个人信息保护影响评估(草稿)

> 依据《人脸识别技术应用安全管理办法》(国家网信办、公安部令第 19 号,2025-06-01 施行)第九条:
> 应用人脸识别技术处理人脸信息,应当**事前**进行个人信息保护影响评估,报告和处理情况记录**至少保存 3 年**。
>
> 本文是开发时写的草稿,按系统实际做法填写。**上线前请公司负责人(或法务)审阅、补签字和日期,定稿后留存。**
> 若认定本功能不属于「人脸识别技术」(见第五节),本评估仍建议保留,作为处理未成年人个人信息的事前评估记录。

| 项目 | 内容 |
|---|---|
| 功能名称 | 学习时用摄像头看孩子在不在座位前 |
| 评估日期 | 2026-10-31(草稿) |
| 个人信息处理者 | 飞鹰教育(及孩子所在的合作校区) |
| 评估人 / 审阅人 | 待填 |

## 一、处理目的、方式是否合法、正当、必要

**目的**: 孩子在家用系统做作业时,家长不在旁边也能知道孩子是不是还坐在屏幕前;孩子离开时页面提醒他回来。

**方式**:
- 只在**孩子的父母或其他监护人同意后**才打开(家长在家长端勾选同意;或家长签纸质同意书,由本班老师登记)。没同意时前端不开摄像头,服务器也拒收相关数据。
- 孩子打开学习页面时,用这台设备的前置摄像头,**每 2 秒在孩子自己的设备上**判断一次「画面里有没有人脸」(BlazeFace 人脸检测模型,只输出「有 / 没有」)。
- **不认人**: 不提取人脸特征、不和任何照片或人脸库比对、不做身份验证或辨识特定个人。
- **画面不上传、不保存**: 视频帧只在浏览器内存里,判断完即丢弃。
- 服务器只收到: 连续 10 秒以上看不到人时「几点离开、离开了多久」;以及「今天摄像头开着 / 孩子没允许 / 设备没有摄像头」。

**必要性**: 家长和老师需要知道孩子在家学习时是否真的在学。只看页面操作(动鼠标、点屏幕)判断不了「人坐在那里但走神」或「人走开了、页面开着」。摄像头只用来判断人在不在,不用来判断是否认真。

**替代方式**: 不开摄像头系统照样能用(切出页面次数和时长、60 秒没操作、听写卡住提示都不依赖摄像头)。摄像头**不是唯一方式**,家长可以不开。

## 二、对个人权益的影响,降低不利影响的措施是否有效

| 可能的影响 | 措施 |
|---|---|
| 孩子在家被摄像头对着,感到被监视 | 学习页面左下角一直显示小画面和「摄像头开着 · 只看你在不在,画面不上传」;只在学习页面开,离开学习页面立即关闭摄像头 |
| 拍到家里其他人或环境 | 画面不上传、不保存;只判断有没有人脸,不记录是谁 |
| 判断错误(光线暗、侧脸)导致误报离开 | 连续 10 秒看不到人才算离开;家长端写明「只能看出人在不在」;离开记录不影响作业成绩和金币 |
| 家长不知情就被打开 | 打开前必须看完告知并勾选;老师登记要确认已拿到家长签字的纸质同意书,并进操作记录 |
| 想关掉却关不掉 | 家长端一键关掉、本班老师也能关;关掉后孩子下次打开学习页面即不再开摄像头 |

## 三、泄露、篡改、丢失、毁损或被非法获取、出售、使用的风险

- 服务器上**没有人脸图像或人脸特征**,即使服务器被攻破,也拿不到孩子的照片或人脸信息。
- 服务器上的离开记录(时间、时长、学习页路径)属于孩子的学习行为数据,保存 180 天后自动删除;家长可以随时一键删除摄像头那部分。
- 访问控制: 家长只能看自己绑定的孩子;老师只能看本班学生;平台与机构管理员按现有权限管理。

## 四、保护措施是否合法、有效并与风险程度相适应

- 告知(第五条): 家长端同意前展示,纸质同意书打印的是同一份文字(后端 `services/focus_watch.notice()`),包含处理者和联系方式、目的和方式、保存期限、必要性和影响、如何撤回。
- 单独同意与撤回(第六条): 摄像头单独一张卡片、单独勾选,不与注册或其他功能捆绑;撤回入口在同一张卡片上。
- 不满十四周岁(第七条): 同意由父母或其他监护人作出;勾选文字为「我是孩子的父母或其他监护人」。
- 存储于设备内、不通过互联网传输(第八条): 画面只在设备上处理。
- 记录(第九条): 同意 / 撤回由谁、何时、哪种方式(家长端 / 纸质),存 `camera_consents` 表;老师登记进操作记录 `camera.consent`。纸质同意书由校区留存。
- 存储数量(第十五条,10 万人备案): 系统不存储人脸信息,不涉及。

## 五、是否属于「人脸识别技术」

办法第十九条把「人脸识别技术」定义为「以人脸信息作为识别个体身份的个体生物特征识别技术」,
「人脸信息」是「与已识别或者可识别的自然人有关的面部特征生物识别信息」。
本功能只判断画面中有没有人脸、不识别身份、不提取或存储面部特征,**可能不属于**办法所称的人脸识别。
但孩子多数不满十四周岁,其个人信息按《个人信息保护法》第二十八条属于敏感个人信息,
因此仍按办法的要求做告知、监护人单独同意、设备内处理和事前评估。**最终认定请法务确认。**

## 六、结论与待办

- 结论(草稿): 处理目的明确、方式影响最小、有替代方式;风险主要是孩子的感受与误报,已通过一直可见的提示、只在学习页开启、可随时关闭来降低。
- 待办:
  1. 公司负责人 / 法务审阅本评估并签字,留存 3 年。
  2. 纸质同意书的留存方式(校区保管 / 拍照存档)由校区定。
  3. 处理目的或方式变化(例如改为上传画面、增加身份识别)时,**必须重新评估**。
